# 雪山气象站

React + Vite + TypeScript 的高海拔自动气象站监控基础项目。提供山地站点环境概览、传感器阵列、观测动态、趋势图和链路状态，保留后续接入真实遥测、卫星同步和历史数据服务的空间。

```bash
npm install
npm run dev
```

## 告警规则管理

值守员可在「告警规则管理」面板中为每个传感器配置告警规则：比较条件（`> ≥ < ≤ = ≠`）、阈值、单位和启用状态，支持新增、修改、停用和删除。

- 服务端每收到新读数（`POST /api/readings`，含内置模拟遥测）即重新评估启用的规则，判断**触发**或**恢复**；
- 触发与恢复都会写入运行日志（观测动态），并保留当时的**读数快照**和**规则快照**，规则后续修改不影响历史记录；
- 状态摘要（传感器正常 / 需要关注 / 告警中）和传感器卡片状态随评估结果实时更新；
- 规则变更（含停用、删除）会立即按当前读数重新评估，解除不再成立的告警。

### API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/alert-rules` | 规则列表（含 `active` 触发状态） |
| POST | `/api/alert-rules` | 新增规则：`{ sensor, name, operator, threshold, unit }` |
| PUT | `/api/alert-rules/:id` | 修改比较条件、阈值、单位、启用状态等 |
| DELETE | `/api/alert-rules/:id` | 删除规则 |
| GET | `/api/alerts` | 当前告警与运行日志（含读数/规则快照） |
| GET | `/api/summary` | 状态摘要：正常/关注/告警中数量、规则统计 |
| GET/POST | `/api/readings` | 查询或摄入传感器读数（摄入后立即评估规则） |
